# BoosterOS APK Project
Latest `BoosterOS-FULLSCREEN(2).html` is bundled as `app/src/main/assets/index.html`.
## Free build with GitHub Actions
1. Create a GitHub repository.
2. Upload/extract this entire project, preserving folders.
3. Open Actions -> Build BoosterOS APK -> Run workflow.
4. After it finishes, open the workflow run and download the `BoosterOS-APK` artifact.
5. Extract the ZIP; install `app-debug.apk` on Android.
